# FRANCHISE OS

Персональная финансово-операционная система владельца сети франшиз.

Первая сеть: **STRIXY — Сокол → Грязовец → Шексна**.

## Реализовано
- дашборд капитала, оборота, прибыли и readiness;
- карточки точек и редактируемый P&L;
- базовые выручки: Сокол 800 тыс. ₽, Грязовец 500 тыс. ₽, Шексна 500 тыс. ₽;
- капитал 3,9–4,0 млн ₽ без кредита;
- сценарии «Консервативный / Базовый / Сильный»;
- персонал: % мастера, личная выручка, начисленная зарплата, взносы, отпускные, больничные, полная стоимость сотрудника;
- фонды: амортизация, корпоративная культура, резерв;
- план открытия каждой точки;
- рассрочки франшизы;
- расчёт безубыточности, маржи и чистой прибыли;
- мобильный интерфейс;
- сохранение всех изменений в localStorage;
- Supabase SQL schema с RLS для следующего этапа persistence.

## Запуск
```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Production persistence
1. Создать Supabase проект.
2. Выполнить `supabase/schema.sql`.
3. Скопировать `.env.example` в `.env.local` и заполнить ключи.
4. Следующим этапом заменить локальный persistence-adapter на Supabase Auth + Database.

> Финансовые значения в приложении являются пользовательскими плановыми допущениями, а не гарантией результата.
