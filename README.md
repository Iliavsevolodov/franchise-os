# FRANCHISE OS

Персональная финансово-операционная система владельца сети франшиз.

Первый проект: **STRIXY** — Сокол → Грязовец → Шексна.

## Цели
- капитал и план открытий;
- P&L по каждой точке и сети;
- сценарии, безубыточность и окупаемость;
- сотрудники и полная стоимость найма;
- амортизационный и корпоративный фонды;
- рассрочки и будущие платежи;
- readiness следующей точки.

Проект строится как расширяемая платформа: позже можно добавлять другие франшизы и бизнесы.
